# Project rules
- Use a bounded local terrain grid and delayed piecewise 3D aircraft curves for coarse-to-fine recording analysis; lock event clock shifts and bound archive requests and ridge-tracer memory to keep broad searches feasible without changing the cinematic simulation.
- User-triggered cinematic demos run their full configured timeline regardless of passive motion preferences, with a Pause/Resume control; preload Earth and map during audio so loading cannot consume the zoom.
- Process multi-gigabyte ADSB.lol historical archives with the offline streaming importer and service-only aircraft_archive_positions table, not browser or edge polling, to keep archive extraction bounded and separate from simulated audio results.
- Load extracted archive CSVs through validated, bounded conflict-safe SQL batches and an approved managed-write adapter only; direct shell writes are restricted and completion must be guarded by database counts.
- Render the hero Earth with Three.js in RotatingGlobe using a public-domain Natural Earth dotted land texture; rotate the sphere around its tilted polar axis rather than transforming a flat picture, with static fallback and reduced-motion support.
- Authenticate OpenSky only server-side using saved OAuth client credentials; never expose provider response bodies or tokens in errors because they may contain sensitive data.
- Analyze recordings locally and query only completed historical aircraft days through archive-flights; show experimental candidate areas, never claim reliable caller locations or substitute demo coordinates when data is missing.
- Record completed daily archive loads in service-only aircraft_archive_days only after CSV row counts are verified; partial extraction never establishes coverage.
- Use Leaflet with credited OpenStreetMap raster tiles for the location-result map, requiring no provider key.
- Keep audio files local in browser memory and revoke object URLs on replacement or unmount.
- Keep all cinematic demo story data and timings in hiker-demo-config; CinematicHikerDemo reuses HikerDemo, RotatingGlobe and LocatorMap to visualize only configured simulation data without touching live services or inferring locations from audio.
- Keep the cinematic demo map camera stationary at its configured neighborhood zoom; drive the search circle from flight progress rather than map zoom so pause/resume keeps both animations synchronized.
- Display the configured geographic demo route as an explicitly labeled fixed-scale schematic anchored near the search center, with arc-length aircraft progress and a shared trail endpoint; street-level zoom cannot keep the full geographic flight in view.
- Keep Technology content in TechnologySection on the home page and redirect legacy /technology links to /#technology; SiteHeader anchors scroll to the section and home callbacks reset the cinematic view.
- Use the retarded-time Doppler model for the teaching visual so sound propagation and the plotted pitch stay synchronized.
- Render scientific concept pictures as accessible token-themed SVG diagrams so their geometry remains accurate and legible at small sizes.
